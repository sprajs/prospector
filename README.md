# Prospector

Prospector is the planned paper-discovery project in a three-part scientific
research workflow.

- **Prospector** will search arXiv and other research-paper sources, identify
  interesting investigations, and export candidate records with their sources.
- **[Reproducible](https://github.com/sprajs/reproducible)** will hold the experiment
  recipes, data references, run records and results for selected candidates.
- **[Irreducible](https://github.com/sprajs/irreducible)** will provide the scientific
  software used to execute those experiments.

A candidate should identify the exact paper/version, the claim or model to test,
relevant observations, and what would be needed to run an investigation. Discovery
is distinct from demonstrating that a claim is correct or an experiment feasible.

This repository is a local project placeholder. No scraper, discovery service,
recurring search, candidate pipeline or scientific execution has been implemented.

Local project: `~/Projects/prospector`.
